# Phase 6: Submission Flow & Acknowledgement Specifications

## Submission State Machine

```
[ Form & Documents Complete ]
             │
             ▼
[ Review Application ] <--- Validates missing fields & documents via applicationValidation.js
             │
             ▼
[ Declaration & Consent ] <--- Checkbox consent & typed name confirmation
             │
             ▼
[ Confirmation Modal ] <--- Prevents accidental submission
             │
             ▼
[ Submitting State ] <--- 4-step progress animation (Validating -> Preparing -> Recording -> Generating)
             │
             ▼
[ Success & Acknowledgement ] <--- Generates BSAI-APP-2026-XXXXXX receipt
```

## Demonstration Disclaimer
All acknowledgement receipts explicitly display:
> *"This is a demonstration acknowledgement generated by Bharat Sewa AI. Official submission and acknowledgement will require integration with the concerned government service portal."*

## Edit Restrictions
Submitted applications transitions to `status: "submitted"`. Accessing `/applications/:id/edit` or editing controls is blocked and safely routed to the application tracking view.
