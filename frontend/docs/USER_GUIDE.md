# User Guide (Citizen / Officer)

## For Citizens
1. **Dashboard:** Access available schemes.
2. **Applications:** Start a draft application. Drafts are safely debounced and auto-saved locally. If you close your browser, your valid draft will still be there.
3. **Assistance Panel:** Click the sparkles icon to receive contextual tips on what to do next.

## For Officers
1. **Officer Login:** Log in via `/officer/login` to assume a mock Officer role.
2. **Queue Management:** Review mock applications, request clarifications, and update statuses using the standard `OfficerLayout`.
