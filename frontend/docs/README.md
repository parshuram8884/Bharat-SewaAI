# Documentation Index

Welcome to the documentation suite for Bharat Sewa AI (Version 1.0.0). This directory contains all technical, architectural, and operational manuals required for demonstrating, maintaining, and understanding the platform.

## Recommended Reading Order

1. **[Handover Guide](./HANDOVER_GUIDE.md)**: A high-level overview of the project's purpose, scope, and final delivery state.
2. **[Architecture](./ARCHITECTURE.md)**: Details the strict frontend-only design, module boundaries, and state management strategies.
3. **[Security Review](./reports/SECURITY_REVIEW.md)**: Outlines the security boundaries and limitations within a simulated environment.
4. **[Demo Guide](./DEMO_GUIDE.md)**: Step-by-step scripts for presenting the core citizen and officer workflows, including error recovery scenarios.
5. **[Known Limitations](./KNOWN_LIMITATIONS.md)**: Crucial reading for understanding what is mocked and what would require real backend infrastructure in a future production release.
